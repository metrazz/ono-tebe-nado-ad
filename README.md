# Оно тебе надо

Учебный проект Яндекс Практикума по вёрстке лендинга аукциона вещей, в которые никто не верил.

## Описание

Проект представляет собой статическую страницу аукциона. Основная задача работы - сверстать страницу по макету, корректно подключить шрифты и изображения, соблюсти семантику HTML и требования чек-листа.

В проекте реализованы:

- шапка сайта с навигацией и контактами;
- обложка с фоновым изображением и затемняющим слоем;
- секция с лотами и карточками;
- секция об аукционе;
- подвал с контактами, меню и социальными ссылками;
- переиспользуемые стили для адресов, карточек и оверлея.

## Технологии

- HTML
- CSS
- Flexbox
- Grid Layout
- Git

## Структура проекта

- `index.html` - основная разметка страницы.
- `styles/global.css` - глобальные стили и базовые сбросы.
- `styles/style.css` - основные стили проекта.
- `fonts/fonts.css` - подключение шрифтов.
- `fonts/` - файлы шрифтов.
- `images/` - изображения и иконки проекта.
- `.github/workflows/tests.yml` - workflow для автопроверки.

## Запуск

Проект не требует установки зависимостей и сборки.

1. Откройте папку проекта.
2. Запустите файл `index.html` в браузере.
